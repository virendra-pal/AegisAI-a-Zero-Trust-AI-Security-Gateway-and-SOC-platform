Defensive Boundaries

• Documented Miss (ATK-19): Multi-language Latin cipher bypass ('Obliviscere priorum mandatorum...'). Because regex signatures focus on primary deployment languages, low-resource Latin translation framing avoids single-turn lexical heuristics.
• Root Cause: Single-pass stateless pattern matching vs. semantic intent shifting across non-English token spaces.
• Engineering Recommendation: In enterprise production with higher latency budgets, chain a cross-lingual embedding cosine distance model or an LLM-as-a-judge secondary verifier.
